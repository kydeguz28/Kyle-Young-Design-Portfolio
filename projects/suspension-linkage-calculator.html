3D Suspension Linkage Calculator

A Python solver and interactive website for inspecting suspension geometry, calculating member forces, and reviewing sizing margins across tire load cases.

Team

Work
Force analysis, visualization, sizing calculations
Tools
Python · HTML · JavaScript
Model
Front and rear double-wishbone suspension

Purpose

Suspension geometry and load analysis.

I developed a Python version of the suspension-force spreadsheet calculations and connected the results to an interactive 3D viewer. The model uses tire loads and pickup coordinates to calculate wishbone, tie-rod, pushrod or pullrod, shock, and rocker reactions.

The website brings the geometry and calculated loads into one place so I can inspect each load path and identify the cases that govern component sizing.

Website features

Four analysis views.

3D geometry
Orbit the assembly, select a corner and load case, inspect members, and display chassis force vectors.
Member sizing
Review peak tension and compression, edit tube dimensions, and inspect yield, ultimate, and buckling margins.
Chassis loads
Inspect interface forces and rocker reactions, including the governing load case at each pickup.
Methods
Trace equilibrium calculations, rocker and shock balance, kinematic iteration, and workbook comparison checks.

Engineering use

Reviewing the load path.

The tool supports geometry review and preliminary component selection. Its results depend on the configured pickup coordinates, load cases, material properties, and joint assumptions. Detailed bearing, fatigue, misalignment, and connection checks remain part of the hardware design process.
