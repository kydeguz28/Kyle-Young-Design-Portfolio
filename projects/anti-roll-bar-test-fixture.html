Project 02 / Formula SAE validation

Anti-Roll Bar Test Fixture

A bench fixture that turned a vehicle dynamics question into repeatable load-deflection data for anti-roll bar stiffness and suspension tuning decisions.

Role
Design, fabrication, validation
System
Formula SAE anti-roll bar
Tools
Dial gauges, displacement sensors, laser-cut mounts
Disciplines
Testing, fixture design, vehicle dynamics

Context

Bench data for a vehicle-level decision.

Anti-roll bar tuning affects vehicle balance, but the team needed a way to connect design targets to repeatable measurements. The fixture made stiffness testable outside the car, giving suspension decisions a clearer data path.

Contribution

Fixture as measurement system.

Kyle selected measurement hardware, designed modular clamping, and arranged the fixture to accept multiple bar geometries with consistent alignment. The work prioritized setup repeatability, robust measurements, and a direct connection back to suspension tuning parameters.

Input
Known applied load
Measurement
Dial-gauge deflection
Output
Anti-roll bar stiffness for simulation feedback
Measurement loop Known load to measured deflection to stiffness feedback.

The fixture turns a setup-sensitive hardware question into repeatable data the suspension team can use.

Process

Load, measure, calculate, feed back.

01
Define stiffness target

Connect roll-stiffness questions to a measurable bench setup.

02
Design fixture

Create modular clamping and alignment hardware for multiple bar geometries.

03
Run controlled tests

Apply known load, measure deflection, and preserve consistent setup conditions.

04
Return to model

Use stiffness data to inform anti-roll bar sizing, linkage geometry, and FLLTD values.

Technical evidence

Data and derivation.

The calculation artifacts show how the fixture translated physical displacement into useful suspension-development data.

Outcome / reflection

What the fixture changed.

The fixture gave the team quantitative stiffness data instead of relying only on assumptions. It reinforced the value of designing the test as carefully as the part: alignment, access, and repeatability are engineering decisions.

Result Suspension tuning moved from assumption toward bench-measured stiffness.

If expanded, the next version would document setup uncertainty more explicitly and make comparisons across bar geometries easier to review at a glance.
