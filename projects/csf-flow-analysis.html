Project 03 / Biomedical flow research

CSF Flow Analysis

A Python workflow for extracting, cleaning, comparing, and visualizing cerebrospinal-fluid flow features from medical imaging and physiological datasets.

Role
Pipeline, cleaning, visualization
Research area
Chiari malformation outcome assessment
Tools
Python workflow
Features
Peak velocity, waveform shape, pulsatility

Context

Making physiological flow comparable.

The research needed transparent analysis of CSF flow features so preoperative and postoperative cases could be compared consistently. The challenge was to clean and normalize complex flow data without hiding the processing steps from the research team.

Contribution

Reproducible analysis, not black-box plots.

Kyle developed a reproducible pipeline to import raw flow data, remove noise, normalize metrics across subjects, compute derived features, and generate visual comparisons. The goal was clarity: researchers should be able to trace how each result was produced.

Individual contribution Pipeline, cleaning, derived features, and visual comparison outputs.

The portfolio does not publish the dataset or repository, so the case study keeps the evidence boundary explicit.

Process

From raw signal to clinical comparison.

01
Import

Bring medical imaging and physiological flow datasets into a repeatable Python workflow.

02
Clean

Remove noise and prepare comparable signals for feature extraction.

03
Normalize

Align metrics across subjects so changes can be interpreted more consistently.

04
Visualize

Translate waveform behavior into comparisons that clinicians and researchers can inspect.

Technical evidence

Workflow artifact.

Outcome / reflection

What changed.

The workflow helped translate fluid-dynamics signals into intuitive preoperative and postoperative comparisons. The most important design choice was transparency: a research tool is more useful when the team can understand the data path.

Design decision Favor traceability over black-box automation.

A future portfolio update should add richer captions around the dataset structure and any confirmed validation results once Kyle can share them publicly.
